# Transportation Management System (TMS)

This prototype system was designed to streamline operations between a logistics company and dedicated transportation carriers. It improves efficiency through automated workflows, increases visibility into driver daily activities, and provides actionable insights based on operational data.

## Features

- **BOL Image Integration**: View Bill of Lading images associated with shipments.
- **Driver Assignment History**: Track historical driver assignments to doors and locations at facilities.
- **Daily Shipment Goals Tracker**: Set and monitor daily shipment goals for each facility.
- **Driver Log Records**: Access previous daily activity logs for drivers.
- **Shipment Analytics**: Compare analytics such as shipments per month and facility wait times.
- **Refuse Load Handling**: Allow drivers to refuse loads with reasons and prompt Out-of-Service (OOS) status.
- **Facility Stops**: Enable drivers to stop at additional facilities or pause current shipments.
- **Trailer Maintenance Management**: Manage OOS (out-of-service) trailers and assign drivers to handle maintenance tasks.
- **Shipment Handoff Between Drivers**: Facilitate seamless transfer of shipments between drivers.
- **Dynamic Assignments**: Update driver, door, and yard move assignments dynamically.
- **Inbound Shipment Integration**: Add inbound shipment data to yard/door status.
- **Driver and Shipment Detail Pages**: Dedicated pages for detailed driver and shipment information.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript, Bootstrap, jQuery, Chart.js, DataTables
- **Backend**: PHP
- **Database**: SQLite3
